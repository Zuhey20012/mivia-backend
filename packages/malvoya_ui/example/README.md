# Birch Market gallery

Every `malvoya_ui` component in one scrollable page, with switches for the brand (Malva, Moss,
Lingon), dark mode, Finnish and large text (1.3).

```bash
cd packages/malvoya_ui/example
flutter create --platforms=android,web .   # once: adds the platform folders (not kept in git)
flutter run -d chrome
```
